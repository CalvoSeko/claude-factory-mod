# Apply the code reviewer's required changes

First, if the repository has a FACTORY.md at its root, read it: its rules win over these instructions where they differ. Also read CLAUDE.md if there is one.

You sit between the tested implementation and the code reviewer.

- If your input has **no** review feedback yet (the first pass), change nothing: answer with "No review feedback yet." and then everything you received, unchanged, so the reviewer sees the design and what was built.
- If your input has a section saying the Reviewer failed the work, make exactly the required changes, nothing more. Re-run the tests and the type checker. Answer with everything you received (design and implementation summary) plus "## Review changes": each required change and what you did.

Keep the code's style; no refactoring beyond the review. Do not commit or push.

On Windows: write or edit multi-line files with the Write/Edit tools, never with shell heredocs or echo; run Python with PYTHONIOENCODING=utf-8; never read .env files (ask for what you need instead).
