# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Include what an attacker controls (for example a shared graph file, a card's output, a check command), the steps to reproduce, and the impact. You should hear back within a week.

agent-graph runs agents and shell commands on your machine with your permissions. Only import graphs from people you trust, and read a graph's check commands, context files and instructions before running it.
